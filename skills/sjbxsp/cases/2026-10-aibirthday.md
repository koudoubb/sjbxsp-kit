## 三、配色（照抄，只改值）

主题「暖珊瑚」，情绪：温暖、亲子、可信。全片 20 个变量写在 `anim/style.css` 的 `:root`，页面内零裸色值；三张重绘界面共用同一套。

```css
:root{
  --ink:#241B36; --ink2:#5A5170; --muted:#9B92AE;
  --brand:#FF6A45; --brand-d:#D9431F;
  --brand-g:linear-gradient(100deg,#FF7A45,#FF4E7A);
  --rose:#EF4C7B;
  --sun:#F4A62A; --sun-t:#FFF3DC;
  --mint:#12A17B; --mint-t:#E3F7EF;
  --danger:#B8402E; --danger-t:#FFEAE5;
  --paper:#FFFBF7; --paper2:#FFF2E8;
  --tint:#FFEDE3; --tint2:#FFF6F1; --gray-t:#F5F0EA;
  --line:rgba(255,106,69,.17);
  --arrow:#F09E7C;
  --hl:rgba(255,183,77,.5);
}
```

三处被现场改过的值，原因记在这里：

- `--hl` 从「主色浅调」改成**金色荧光** `rgba(255,183,77,.5)`：原来深珊瑚字 + 珊瑚高亮条，观众读成"这几个字被划掉了"。
- `--arrow` 从 `#F7C9B6` 改成 `#F09E7C`：前者在 `#FFFBF7` 暖白底上几乎不可见，投影到手机上完全消失。
- `--danger` 用 `#B8402E`（更暗更灰）而不是纯红：主色本身就是橙红，负向色不压深就分不出"坑"和"重点"。

## 五、口播改写：人称统一为「你」

原片是作者自述（"我用的是豆包"、"我在后台就能看到"、"我也不用手动建文件夹"）。成片改成**对观众说话**：

| 原片 | 成片 |
|---|---|
| 我用的是豆包 | 你可以用豆包 |
| 我在后台就能看到 | 你在后台就能看到 |
| 我也不用手动建文件夹 | 你也不用手动建文件夹 |

规则：教程/案例类口播的主体是「你」，不要用「我」讲自己的操作——观众代入不进去，且画面上的界面是"示意"而非"我的后台"。只在开场第一段可以留一句「我把这套流程拆一遍」建立讲述者身份，其余全部第二人称。批量改完要 `grep -n "我" speech.txt` 逐条过一遍，确认剩下的「我」都是引用原话或必须的第一人称。

## 六、这次定下的技法（已写进规范）

- 界面重绘优先：有文字的界面默认重绘，原片 UI 截图每支片 0–1 张（见 `references/ui-mock.md`）
- 设计尺寸 = 槽位尺寸，不按 390×844 设计再缩
- 三张界面共用一套色变量，跟着卡片主题走
- 页与旁白强绑定：讲到哪个界面，画面就出现哪个界面，顺序不能错（本片 P11 三格成片原来排成"角色→穿越→画作"，与旁白"先看到画、再穿越、再角色"不符，重排后才对）
- 封面不放图注文字，改在图片角落放白色角标「AI 生成成片」——图注压在图上会挤成一团

## 七、这次踩的坑

1. **静态截图缩进卡片，字只剩 3–4px。** 原片 852×480，后台表格缩进 928px 卡片、再随成片缩到手机屏，实测 3–4px，彻底读不出。这是全面改重绘的直接原因。
2. **重绘件自己也没达标。** 第一版按"看起来像"做，设计尺寸下正文只有 11px，缩到成片仍是灰点。定下下限后才合格。
3. **高亮条与标题同色 → 读成删改痕迹**，改金色荧光。
4. **箭头色在暖白底上不可见**，加深两档。
5. **重绘 PNG 带黑边。** 截图边缘有半像素底色，拼进卡片像描了黑框。用行列均值 < 12 判定，四边 trim 后重新存。
6. **P12 撑不满页面**：三行短句 + 循环箭头，内容只占 2/3 高度。解法是把卡片撑到 `top:1150`、箭头加粗加深，而不是加废话。
7. **克隆音色不可用时的处理**：`lartai` MCP 被禁用、本机无 torch 系 TTS，最终用 `edge-tts zh-CN-YunyangNeural rate -4%` 占位，并明确告知用户"换真音色不用重渲画面"。占位音也要整篇一次生成，别逐句拼。
8. **字幕交叉验证时小模型整体早 1.1 秒**：`whisper -m small` 有自己的词级前置填充，系统性偏早，不是字幕错。改用音频能量起音点复核，字幕起点误差 ±0.15 秒即合格。
