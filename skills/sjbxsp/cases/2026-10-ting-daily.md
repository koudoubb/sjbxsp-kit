# 案例：全程不说话的 55 万播放频道拆解（抖音改编 · 2026-10）

题材：把抖音 @超叫兽 一条 4:51 的频道拆解（分析 YouTube 频道 `Ting Daily Life in China`：19.1 万订阅、平均 55 万播放、月更 6 条、估收 137 万）改写成 6:20 竖屏教程片。
项目目录：`<project>/`（本地路径略）

**这支片的价值在"实拍"**：全片 27.4% 是原片影像，四段录像分别承担"频道长什么样 / 怎么切镜头 / 现场数给你听 / 六种机位怎么换"。纯卡片版被否过一次。

## 三、配色

主题「深炭黑 + 暖橘」，情绪：冷静拆解 + 一个高温强调色。**上一支片是暖珊瑚，这支如果继续浅蓝会被要求返工。**

| 用途 | 值 |
|---|---|
| 画布底 | `#0E1014`，径向渐变 `#241A14 → #14171D → #0B0D11` |
| 主色 / 强调 | `#FF6A2B` / `#FF9A5E`，亮部数字 `#FF8A4C` |
| 金（数据 / 反例） | `#F0B429`，深底 `#241A10`，文字 `#F6E2C0` |

| 卡片 | `#171A20`、`#24272E`、`#2E211B` |

| 光斑 | `.14` / `.09` / `0`（第三颗关掉） |

批量换色映射（浅蓝 → 深炭黑）：`#F7F9FC→#0E1014`、`#EDF2FB→#12151B`、`#2B5BD7→#FF6A2B`、`#5E86EE→#FF9A5E`、`#1B3FA8→#FF8A4C`、`#16203A→#F3EFE6`、`#4E5B75→#BFB7A9`、`#8B97AD→#8D8577`、`#E8EFFD→#2E211B`、`#FFF7E8→#241A10`、`#3A2A05→#F6E2C0`、`#17348C→#8A3A12`。

**本片 `style.css` 没有 `:root`/`var()`，色值是硬编码的**，所以换主题靠 sed 批量替换 + 人工查残留。规范要求走变量，做下一支时先把 `:root` 建起来。

|---|---|---|---|---|---|---|---|
| 1 | P3 | 40.6–63.1s | A 嵌框 | ref 3.5s 起 22.5s | `1080:497:0:90 → 922:424` | `79:543` | maskA 922×424 |

| 4 | P9 | 193.10–223.54s | B 整页 | ref 153.2s 起 22.2s | `1024:580:56:96 → 982:553` | `49:319`（洞内） | 无 |

P9 的做法值得抄（素材比页面短）：

```bash
ffmpeg -y -loop 1 -framerate 25 -i anim/p09-bg@2x.png \
  -ss 153.2 -t 22.2 -i assets/ref.mp4 \
  -filter_complex "[1:v]crop=1024:580:56:96,scale=982:553,setsar=1,setpts=1.2*(PTS-STARTPTS),fps=25,tpad=stop_mode=clone:stop_duration=3.8[v];\
[0:v]scale=1080:1480,setsar=1[bg];[bg][v]overlay=49:319:eof_action=pass,format=yuv420p[out]" \
  -map "[out]" -t 30.44 -r 25 -c:v libx264 -crf 17 -preset medium -an build/cutD.mp4
```

22.2s 素材 → 慢放 1.2x 成 26.6s → 尾部定格 3.8s = 30.44s，正好等于该页时长。

整页视频页的底版是独立 html（`p09.html`），1080×1480，同款 `.top` + `h2` + `.lead` + `.hole`（`left:46;top:316;988×559;border:3px`）+ 六个机位卡 + 两条注。

## 五、口播改写

原片是第一人称拆解（"我统计了一下她视频里面的镜头"），成片保留讲述者视角（这是"我拆给你看"的体裁，不改「你」），只做 TTS 友好处理：数字全汉字（`29 岁`、`19.1 万` → 十九点一万）、`RPM` 之类的词全部展开成"每一千次播放"、删掉时间码与括号。

**返工代价**：第一版擅自压缩改写、删掉原片的计数段和四条结论，被要求"重新检查视频"，另存核对稿重做。口播稿一旦要"忠实于原片"，就不能按自己的节奏删减——先出带时间码的核对稿给用户过。

## 六、这次定下的技法

- 讲节奏/机位的页必须放原片，卡片只做归纳；四段实拍合计 27.4%
- 计数演示用"整页视频页 + 下方数字格"：数字格是事后统计，视频是原始证据，两者同屏最有说服力
- 素材短于页面时：慢放 ≤1.2x + 尾部定格 ≤4s
- 整页视频页底版高度固定 1480，给字幕带（y≥1500）让位
- 封面独立成页（`anim/cover.html`，1080×1440）：三格实拍 + 137 万 + 19.1 万订阅 + 底部信息带

## 七、这次踩的坑

1. **默认浅蓝被否**。现象：第一版全片浅蓝底 + 蓝主色，用户回"风格不要固定用浅蓝色，根据主题随机，封面要有点击欲望"。根因：照着上一支片的配色惯性改。解法：每支片写卡片前先定一套主题色，封面单独设计（大数字 + 实拍 + 高对比色带）。
2. **纯卡片讲节奏被否**。现象："数一数几个数换一次镜头这个要用视频剪辑到里面去，不要只用文案"。根因：把"证据"做成了"结论卡"。解法：分镜阶段就标出哪几页必须是影像（见 `references/cutaway.md`）。
3. **批量换色漏了三处浅色**：`#FFF7E8`、`#3A2A05`、`#17348C` 残留 + 光斑过强，整屏发棕。解法：替换后 `grep` 一遍旧色板全部 12 个值，再压光斑 opacity。
4. **`tpad` 放在 overlay 之后 → 洞里全黑**。视频 EOF 后 overlay 已输出底版帧，tpad clone 到的是空帧。tpad 必须加在视频端（`[1:v]...fps=25,tpad=...`）。
5. **保存笔记 500**：填表脚本里 `map = { source: "作品来源" }` 然后 `vm.model.source = 值`，写进了表单没绑定的键（真正绑的是 `from`）。`delete vm.model.source` 后同一份 payload 立刻 200。
6. **按预览图目测坐标偏小约 1.7 倍**，误判"下半页是空区"，插视频压住占比条与列表。解法：先 `grep` 页面里的 `top:` 数值，不要用缩放后的截图估。
7. **小模型转写字幕整体晚 1.57s**：成片音频开头有 0.53s 静音，判为小模型滞后，没有挪字幕。
