# 案例库：做过的片子，照着改

每个案例是一份**可复用的实拍参数**，不是心得。开工前先找一个题材最接近的案例，抄它的规格、配色、页面结构、界面重绘尺寸；**只抄结构，不抄文案**。

## 怎么用

1. 读案例的「成品参数」和「页结构」，对一遍自己的分镜表页数与时长。
2. 抄「配色」整段 `:root`（改值不改变量名），或从 `references/layout-rules.md` 的四套主题里选一套。
3. 若案例里有同类界面（表单 / 后台 / 对话），直接拷它 `anim/ui/` 下的 html 当起点，改文案与尺寸。
4. 读案例的「这次踩的坑」，先避一遍再动手。

## 每次做完追加一份

- 文件名 `YYYY-MM-<一句话题材>.md`，如 `2026-11-petportrait.md`
- 字段照 `_TEMPLATE.md` 填，**必填**：成品参数（时长/帧数/字节/响度）、页数与页时长表、`:root` 全量色值、界面重绘清单（文件/尺寸/字号）、踩过的坑
- 只写**实测数字**。不写「效果很好」「用户很满意」这类无口径评价
- 写完在 README 索引表加一行
