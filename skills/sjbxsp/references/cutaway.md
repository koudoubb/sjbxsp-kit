# 实拍片段：把原片影像嵌进卡片

讲"节奏、机位、界面长什么样、成片什么效果"的段落，**只放文字卡片是废的**。观众要看的就是那几秒画面。这类段落一律嵌原片片段，卡片只做归纳。

一支 14 页的片子，嵌 3–5 段实拍是常态；全片纯卡片会被要求返工。

## 哪些段落必须是影像

| 旁白在讲 | 画面必须是 |
|---|---|
| 切镜头的频率、几秒一换 | 原片**连续播放**，让观众自己数 |
| 机位怎么换（远景/近景/手持/空镜/三脚架） | 原片**连续镜头**，一段里换好几种机位 |
| 某个频道/账号/后台长什么样 | 原片里的真实页面（或重绘件，见 `ui-mock.md`） |
| 成片效果、作品长什么样 | 成片画面 |
| 操作过程、点击、翻页 | 录屏片段 |

反过来，纯观点、总结、对比、数字页继续用卡片——**不要为了"有视频"把每页都做成录像**，节奏会死在长镜头上。

## 三种嵌法

| 形态 | 用在哪 | 做法 |
|---|---|---|
| A 嵌框（小窗） | 页面上还有别的信息要讲（榜单、占比、步骤） | 卡片留一个 `.hole`，视频叠进去，圆角蒙版 |
| B 整页视频页 | 这一页就是在"放片子"（节奏演示、机位演示） | 单独一个 html 出 1080×1480 底版，视频叠满，字号说明压在上/下 |
| C 全屏视频页 | 原片本身就是全屏竖屏画面 | 视频直接 1080×1480 铺满，无底版 |

**B 和 C 的底版高度固定 1480，不是 1920。** 字幕已经烧在成片里（y≥1500），整页 overlay 铺到 1920 会把字幕盖掉。1480 是"内容区上限"，字幕带自然保留。

## 三个必算的数

### 1. 洞的比例 = crop 的比例

先定洞的宽高，再反推裁切框。反了就会变形或被拉伸。

```bash
# 洞内 982×553（洞 988×559 减 3px 边框）
# 比例 1.776 → crop 取 1024×576 或就近的 1024×580，再 scale 到 982×553
[1:v]crop=1024:580:56:96,scale=982:553,setsar=1
```

比例差一点（<1%）看不出来；差 5% 以上就是明显压扁。

### 2. overlay 坐标 = 洞的 left/top + 边框宽

`.hole{left:46;top:316;border:3px}` → `overlay=49:319`。用 46:316 会把边框盖掉（边框在底版上，被视频压住就没了）。

### 3. 时间偏移写进 setpts，不要用 -itsoffset

```bash
[5:v]fps=25,setsar=1,setpts=PTS-STARTPTS+164.68/TB[cm]
[v2][cm]overlay=0:0:eof_action=pass
```

`eof_action=pass` 让片段结束后露出底版，不会黑屏。

## 素材不够长怎么办

成片一页 30 秒，原片对应段落常常只有 20 秒。三条路，按优先级：

1. **慢放 ≤1.2 倍**（`setpts=1.2*(PTS-STARTPTS)`）。1.2x 慢放在风景/走路/空镜上看不出来，还能让观众看清机位变化。超过 1.25x 就开始像卡带。
2. **两端各多取 1–2 秒**（前一页的尾巴、后一页的开头），只要画面仍是同一场。
3. **尾部定格补足**（`tpad=stop_mode=clone:stop_duration=N`），控制在 3–4 秒内，且定格时段落尾句本身就在收束。

**tpad 必须加在视频端，不能加在 overlay 之后。** 放在 overlay 之后，视频 EOF 后 overlay 已经在输出底版帧，tpad clone 到的是"空洞底版"，画面会变成一片空白（实测：30 秒页的后 4 秒洞里全黑）。

## 顺序：叠加放在合成之后

`compose.py` 出的是带字幕的成片，实拍片段是**后置叠加**：

```
compose.py → build/final.mp4（含字幕）
        ↓  overlay.sh（crop → scale → fps → setpts → overlay）
build/final.mp4（含实拍）
```

好处：不用重跑逐帧字幕合成；坏处：叠加区必须自己避开字幕带（y≥1500），且叠加前要备份上一版（`final2.mp4` / `final-pre09.mp4`），改坏了能回退。

一次跑完所有片段，别一段一段叠——每叠一次就重编码一次，画质掉一层。

## 原片录屏的裁切

原片是"分析者录屏 + 他本人的镜头小窗"时，只裁播放器画面区，把浏览器标签栏、地址栏、评论区、右侧推荐、下方人脸全部裁掉。

```bash
# 原片 1080×1920，播放器画面约在 (56,96)–(1080,676)
crop=1024:580:56:96
```

裁之前先抽 3 帧确认边界（浏览器 chrome 有没有进来、画面自带的硬字幕有没有被切一半）。**原片自带的英文字幕要完整保留**，它是"这是真原片"的证据；切掉一半反而像事故。

## 检查清单

- [ ] 每段实拍都和该时段旁白对得上（讲"空镜"时画面就是空镜）
- [ ] 洞内无黑边、无错位、边框可见（抽帧放大看四角）
- [ ] 片段首尾不出现原片的黑帧/静帧/加载转圈
- [ ] 定格总时长 ≤4 秒，且定格时旁白在收束而不是在讲新东西
- [ ] 字幕带 y≥1500 没被盖住（抽查 3 帧）
- [ ] 全片实拍总时长占比 20–35%；超过 50% 就变成搬运，低于 10% 等于没做
- [ ] 叠加前后的总时长完全一致（本片 379.913s 前后一致）
