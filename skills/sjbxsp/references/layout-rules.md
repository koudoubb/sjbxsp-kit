# 版式与字幕硬规范

竖屏 1080×1920，25 fps。所有数值来自实拍稿（v2）实测，不要凭感觉改。

## 画布分区

| 区域 | y 范围 | 用途 |
|---|---|---|
| 顶栏 | 88–160 | `.top`：左侧 pill 标签 + 右上两位页码 |
| 主标题 | 236–470 | `h2` 84px / 封面 `h1` 98px，`line-height:1.16` |
| 内容区 | 470–1600 | 卡片、截图、图表，**不要越界到 1600 以下** |
| 字幕带 | 1500–1920 | 独立图层，白字黑边，最多两行 |
| 3:4 封面安全区 | 240–1680 | 只有第一页需要遵守；区四边还要再内缩 92px |

- 左右边距统一 76px，内容宽 928px（封面页用 96px / 888px，见下节）。
- 底部标签行 `bottom:334px`（封面，内含安全区内边距）/ `bottom:318px`（内容页），给字幕带让位。
- 内容页底部若放结论条，`top` 不超过 1260，高度约 90–110px。

## 封面（第一页）专用

封面要过两道裁切：平台先按 3:4 裁（y 240–1680），列表页还会再裁圆角。所以**光落在安全区内不够，安全区内还要再留一圈内边距**。

### 双层安全区

| 层 | 范围 | 要求 |
|---|---|---|
| 第一层：3:4 裁切区 | y 240–1680，x 0–1080 | 文字与图形不得越界 |
| 第二层：内边距 | 四边各 ≥ 92px（相对裁切区） | **圆角胶囊、色块、插画都不许贴边或紧靠** |

内边距换算到 1080×1920 画布：上边 y ≥ 332，下边 y ≤ 1588，左右 x ≥ 92。

### 实拍稿坐标（v3 定稿，直接抄）

| 元素 | 位置 |
|---|---|
| `.top`（pill + 页码） | `top:334; left:96; right:96` |
| `.kick` | `top:416; left:96`，46px |
| `h1` | `top:500; left:96; width:888`，98px / 1.16 |
| `.num` | `top:760; left:96`，数字 168px |
| `.lead` | `top:958; left:96; width:888`，31px |
| 插画 `.art` | `left:337; top:1086; 406×406`（居中，左右各 337） |
| 标签行 | `left:96; bottom:334` |

整体内容跨度 334–1586，四边最小留白 94px。

### 背景必须铺满全画布

`.g1/.g2/.g3` 光斑与 `#stage` 渐变要覆盖整个 1080×1920，不能只在安全区内画背景。否则裁出来的封面上下就是一片纯黑，很丑（`make_cover.py` 会检测四边亮度并报错）。

### 出封面：2 倍超采样，不要 1 倍直出

```bash
# 1) 2x 渲母版（2160x3840）
python scripts/render.py cover-hd --base <project>
# 2) 裁 3:4 + 出上传版
python scripts/make_cover.py --base <project> --src anim/cover-hd.png
```

| 产物 | 尺寸 | 用途 |
|---|---|---|
| `anim/cover-hd.png` | 2160×3840 | 母版 |
| `cover-3x4-2160x2880.png` | 2160×2880 | 留档 |
| `video-cover-1080x1440.jpg` | **1080×1440** | 上传 |

**上传版宽度至少 1080，与成片一致。不要再用 500×667**——平台会放大显示，肉眼可见发虚。

### 改完必查

```bash
python scripts/render.py safe --base <project> --page 1
```

打印每个元素距裁切区四边的像素，任何一项 < 92 都算不达标（退出码 2）。

## 字幕

| 项 | 值 |
|---|---|
| 字号 | 58px（`subtitle.html`），字重 800 |
| 描边 | 4px 黑边（八向 text-shadow）+ 10px 26px 投影 |
| 行高 | 1.42 |
| 两行宽度上限 | 显示宽度 16.2（中文计 1，其他计 0.55） |
| 单条字幕宽度上限 | 显示宽度 29（= 两行容量） |
| 基线 | 字幕块底部距画布底 92px |
| 最短显示 | 0.55s |

字幕带独立渲染成透明 PNG（1080×420），再由 `compose.py` 逐帧 alpha 合成。**不要用 ffmpeg `drawtext`/`subtitles`**：本机 ffmpeg 无 libass。

## 断行规则（三条重罚，缺一不可）

`gen_subs.py` 的 `balance()` 已经实现：

1. 数字 + 量词之间不断（`五|条`、`四十二|万`）→ +12
2. 常用双字词中间不断（`就|是`、`频|道`）→ +12
3. 英文单词内部不断（`Tyle|r`、`Inside China L|ives`）→ +30

另外：末行少于 4 个显示宽度 +3 分；标点后断行 −1.6 分；空格处断行 −1.0 分。

## 配色：按主题定，不固定一套

**没有默认色板。** 每支片先按选题情绪定一套 8 个变量，写进 `style.css` 的 `:root`，全片只在这一处改色；页面里禁止写裸色值（一律 `var(--xxx)`）。

### 定色三步

1. **抓情绪**：这支片让人感觉什么？温暖 / 冷静 / 锋利 / 高级？
2. **定主色**：一个饱和度高、在白底上认得出的色。冷暖决定气质。
3. **配深与底**：主色压深得到 `--brand-d`（用于强调字与大数字），主色调到 8% 得到 `--tint`（卡片底），底色用主色的极浅暖/冷调而不是纯灰。

### 变量表（照抄，只换值）

| 变量 | 用途 |
|---|---|
| `--ink` / `--ink2` / `--muted` | 标题 / 正文 / 辅助说明（三级文字） |
| `--brand` / `--brand-d` / `--brand-g` | 主色 / 深主色 / 主色渐变（胶囊、按钮、进度条） |
| `--tint` / `--tint2` / `--gray-t` | 浅主色底（强调卡）/ 更浅底 / 中性底（"以前"侧） |
| `--sun` / `--sun-t` | 强调金 / 金底（结论条、高亮） |
| `--mint` / `--mint-t` | 正向、已完成 |
| `--danger` / `--danger-t` | 负向、坑、风险 |
| `--paper` / `--paper2` | 画布底色两档 |
| `--line` / `--arrow` / `--hl` | 描边 / 箭头 / 标题高亮条 |

### 四套现成主题

| 主题 | 适用 | `--brand` | `--brand-d` | `--tint` | `--sun` | `--ink` |
|---|---|---|---|---|---|---|
| 暖珊瑚 | 情感、亲子、生活、案例故事 | `#FF6A45` | `#D9431F` | `#FFEDE3` | `#F4A62A` | `#241B36` |
| 靛蓝 | 数据、科技、B 端、商业分析 | `#2B5BD7` | `#1B3FA8` | `#E8EFFD` | `#E8B34A` | `#16203A` |
| 墨绿 | 知识、成长、干货、书单 | `#1F8A70` | `#12604D` | `#DFF2EB` | `#D9A227` | `#12211C` |
| 绛紫 | 审美、女性、美妆、设计 | `#8B4FD6` | `#5F2FA6` | `#F2E8FB` | `#E7A93C` | `#1D1526` |

### 硬规则

- **一套主题贯穿全片，包括重绘界面。** `anim/ui/ui.css` 的 `:root` 必须来自 `anim/style.css`，改一处两处都变；界面单独配一套色，会和卡片像两个产品。
- 正文与底的对比度 ≥ 7:1；浅底卡片上的字要用 `--brand-d` 而不是 `--brand`。
- **高亮条（`--hl`）不能与标题字同色系**：深色字 + 同色高亮会读成"划掉"。深字配金色荧光 `rgba(255,183,77,.5)`，或浅字配深色底。
- **箭头（`--arrow`）要比主色深一到两档**，浅色调在暖白底上压到成片里会消失。
- 主色本身是红/橙时，负向色必须更暗更灰（如 `#B8402E`），否则"坑"和"重点"分不出来。
- 一页最多两种强调色（主色 + 金）；薄荷/负向只用在语义位置上。
- 字幕永远是白字黑边，不跟主题走。
- 数字一律 `'DIN Alternate'`，中文 `PingFang SC`。
- 事实/数据条用 `--tint` 底 + `--brand` 左边框；判断/结论条用 `--sun-t` 底 + `--sun` 左边框。一页最多一条。


## 数字与口径

- 每个数字必须带口径与单位：`42.3 万元`、`1,961 元`、`475 万次播放`、`11.6 万订阅`、`访谈镜头占 40%`。
- 估算值必须显式标注「估算」及依据（如「按每千次播放 5 美元估」），不与实收数据混排。
- 同一份成片内同一指标单位写法保持一致。

## 动效

| `data-a` | 效果 | 典型参数 |
|---|---|---|
| `in` | 上浮淡入 | `data-d` 0.1–2.0，`data-y` 40（负数=向下） |
| `pop` | 弹性放大 | `data-dur` 0.4–0.75 |
| `num` | 数字滚动 | 必须写 `data-to` 与 `data-dec` |
| `bar` / `wipe` | 横向展开 | 用于下划线与分隔线 |
| `grow` | 纵向展开 | 柱状图 |
| `pulse` | 呼吸 | 强调点 |

- 同一页元素 `data-d` 依次递增 0.12–0.2 秒，形成节奏；整页动效在 3.2s 内收完（渲染 4 秒，末帧停住）。
- 背景 grid 与 glow 已由 `engine.js` 按 `t` 自动漂移，不需要额外写动画。
