# 已经踩过的坑（照做能省半天）

## 字幕

**后段字幕越来越晚。** 根因是用 ffmpeg `concat` 把 N 张字幕 PNG 拼成 filmstrip，每段多出约 1 帧，3 分钟累计漂 2.5 秒。正解：`compose.py` 逐帧解码 rawvideo，按 `t = i/fps` 精确查当前字幕，numpy 直接合成字幕带。零累积误差。

**对齐会越修越坏。** 两种错法都试过：
- 游标式顺序对齐（按顺序往前推）→ 逐条累积漂移，第 20 条起晚 1.9 秒；
- 在粗定位 ±2.8s 时间窗内重新匹配 → 把本来正确的英文/数字处改错（34.31 改到 32.72 又改回来）。

正解：全局 `difflib` 字符映射给初值，**直接采用**，只做单调化与不重叠截断。`align.py` 现在的实现就是这个，不要加"精修"。

**不要用同一份 ASR 自查。** 自证会漏。用另一个模型（如 `whisper -m small`）重转一遍交叉验证，偏差 >0.7s 的条目再回查 medium 的 segment 时间；实测 medium 的 segment 级时间本身就准，别用词级插值去"修"。

**小模型整体偏早不是字幕的错。** `whisper -m small` 重转结果可能**系统性早 1.1s** 左右——那是它自己的词级前置填充，不是成片字幕漂了。判定要看"是否整体平移"：把所有条目偏差算中位数，中位数接近 0、离散小就合格。用音频能量起音点（`build/onset.py`）独立复核，字幕起点误差 ±0.15s 即通过。

**字幕断行不能按字数硬切。** 会把"四十二万"拆成"四"+"十二万"、"Tyler"拆成"Tyle"+"r"。规则见 `layout-rules.md`。

## 渲染

**ego-browser 的 node 拿不到环境变量。** `ego-browser nodejs < x.mjs` 里 `process.cwd()` 是 `"/"`，`process.env` 只有十几个键（自定义变量全部丢失），`process.argv[1]` 是可执行文件路径、传不进参数。所以**不要在 mjs 里读 `process.env.SJBX_*`**，也不要指望命令行参数——路径与数值必须由 Python 在生成脚本时写进正文。`scripts/render.py` 就是干这件事的壳：三个 `.mjs.tpl` 在 `assets/tpl/`，替换占位符后写到 `<project>/build/_sjbxsp_tmp.mjs` 再执行，完事删掉。

**`page.setViewportSize` 不存在。** 视口必须用 `page.cdp("Emulation.setDeviceMetricsOverride", {width,height,deviceScaleFactor,mobile})`。

**透明截图**用 `page.cdp("Emulation.setDefaultBackgroundColorOverride", {color:{r,g,b,a:0}})`，页面 body 背景也要设 `transparent`。

**不要逐帧渲整片。** 1080×1920 单帧约 0.47s，4 分钟要渲 47 分钟。每页只渲前 4 秒（100 帧），其余交给 `tpad=stop_mode=clone` 延长。

**ffmpeg 没有 libass。** 这个构建没有 `subtitles` / `ass` 滤镜，别浪费时间试 ass 方案。

**`OUT.mkdir(exist_ok=True)` 会抛假 EEXIST。** 沙箱 broker 的已知问题，用 try/except 或 `mkdir(parents=True, exist_ok=True)` 包住即可，不要以为是权限问题。

**`np.frombuffer(...)` 返回只读数组。** `ValueError: assignment destination is read-only`，必须 `.copy()`。

**`-vf vstack` 多输入会报错。** 拼字幕带预览图改用 PIL 拼。

## 封面

**只把元素放进 y 240–1680 是不够的。** 平台在 3:4 裁切后还会再裁圆角，贴着安全区边缘的胶囊标签会被切掉一截，看起来"顶到边"。第一页元素要在安全区里**再内缩 92px**，圆角矩形、色块、插画都不要贴边。用 `render.py safe` 量，不要目测——肉眼很容易把 20px 当成"差不多"。

**封面上下出现黑边，不是裁切 bug。** 根因是把背景画在了安全区内、安全区外留空，裁出来上下就是纯背景（深色卡片会变成一条黑边）。背景渐变与光斑必须铺满整个 1080×1920。`make_cover.py` 会检查四边亮度，低于 14 直接报错。

**千万别再用 500×667 的上传版。** 成片是 1080 宽，封面缩到 500 再被平台放大，肉眼可见发虚。上传版宽度至少 1080（3:4 即 1080×1440）。同时母版要 2 倍超采样渲染，1 倍直出即使尺寸够也偏软。

**`page.screenshot` 的 `scale:"device"` 会报参数校验失败。** 当前 ego-browser 只接受 `"css"`；`deviceScaleFactor:2` 也拿不到 2x 像素。要真 2x 就用 `render.py cover-hd` 的做法：视口设成 2160×3840，再给 body 加 `zoom:2`，让浏览器按放大后精度重新栅格化。

**只改了一页不用重渲整片。** `render.py frames --from 1 --pages 1` 只重渲封面页，再跑 `compose.py` 重新合成（约 4 分钟），其他页帧原样复用。

## 版式与配色

**高亮条与标题同色 = 读成"划掉"。** 深色标题 + 同色系高亮条，观众第一眼理解成删改痕迹。高亮一律金色荧光（`rgba(255,183,77,.5)`），或反过来用浅字配深底。

**浅色箭头在暖白底上会消失。** `#F7C9B6` 在白底上肉眼勉强，压到成片里完全看不见。箭头色要比 `--brand` 深一到两档（本片定到 `#F09E7C`），并在成片尺寸下回看一次。

**主色是红/橙时，负向色必须更暗更灰。** 否则"坑/风险"和"重点"用同一个色，语义打平。本片 `--danger:#B8402E`。

**图序必须跟旁白走。** 三格成片原排"角色 → 穿越 → 画作"，旁白却是"先看到画、再穿越、再角色"，顺序错了观众会出戏。排完逐页对一遍旁白句序，不要按素材拿到的先后排。

**卡片撑不满页面，先撑卡片不要加废话。** 短句页面（三行 + 一个循环箭头）常只占 2/3 高度。解法是把卡片高度顶到内容区下沿（`top` 到 1150–1260）、箭头加粗加深，而不是补两句水词。

**封面别在图里压图注。** 图注写在封面上会挤成一团。要标来源/性质就在图片角落放白色小角标（如「AI 生成成片」），压在卡片图注里。

## 口播视角

**教程/案例类口播的主体是「你」，不是「我」。** 原片作者自述"我用的是豆包""我在后台就能看到"，直接搬进成片会让观众代入不进去，也和"界面示意"冲突。统一改成"你可以用豆包""你在后台就能看到""你也不用手动建文件夹"。只在开场第一段留一句"我把这套流程拆一遍"建立讲述者身份。改完 `grep -n "我" speech.txt` 逐条过，剩下的「我」必须都是引用原话。

**克隆音色拿不到时不要卡住。** 工具链里没有可用 TTS/voice_clone 时，先用 `edge-tts zh-CN-YunyangNeural rate=-4%` 占位（同样整篇一次生成），并在交付说明里写明"换真音色只换音频、画面不用重渲"。不要为了等音色停掉整条流水线。

## 抽帧核对

**别用 `glob('qa/p*.png')` 排序。** 字符串排序下 `p04 < p119 < p16`，拼出来的联系表页序全乱，会误判成"视频页序错了"。按时间点排序要写成显式数值列表。

## 配音 / 剪辑

**一集一稿、一次性生成。** 逐句合成再拼必然音色漂移、气口断裂。不满意整章重生成。

**口播稿只写能读出来的中文**：数字用汉字、单位用中文、不写英文缩写与括号、破折号换逗号。时间码不能进稿子（会被念出来）。频道名等专有名词保留英文。

**时间轴不要手抄。** 整篇音频 → 转写 → 字符级对齐 → 字幕与分镜时间自动派生。

## 素材截图

**原片截图塞进卡片 = 观众一个字都看不清。** 实测：原片只给到 852×480，后台表格里的字缩进 928px 宽的卡片、再随成片缩到手机屏，最后只剩 3–4px。截图能"证明存在"，但传达不了信息。凡是有文字的界面（后台/表单/聊天/订单页），一律按 `references/ui-mock.md` 重绘；只有成片画面、实拍照片才保留原素材。

**重绘件自己也会不达标。** 第一版重绘按"看起来像"做的，设计尺寸下正文只有 11px，缩进成片照样是灰点——重绘不等于自动可读，字号下限必须逐张量。

**重绘尺寸要照卡片槽位定，别照手机屏幕定。** 按 390×844 设计再塞进 400×535 的槽位，等于把整页缩一半，字号全废。先量槽位（如 400×535、928×427），html 直接按这个尺寸写死，1 CSS px 就是卡片里 1px。

**重绘界面要跟卡片同色系。** 界面用自己单独的配色，会和卡片像两个产品。把 `style.css` 的 `:root` 搬进 `ui/ui.css`，三张图立刻统一。

**重绘 PNG 会带黑边。** 截图四边常有半像素底色，拼进卡片像描了黑框。按行列像素均值 < 12 判定黑边，四边 trim 后再用，不要用固定像素裁。


**原片截图顶部带浏览器 UI。** 统一 `crop((0, 62, 1080, 1300))` 去掉地址栏；频道页截图用 `object-position: top center`，保证频道名与订阅数不被裁掉。

**需要的画面可能不在首选时间点。** 例如频道页只在 22–26s 出现，先抽帧探测（每 2 秒一张拼联系表）再定位，不要凭时间码硬猜。

**图注别写"原片演示"** —— 换成重绘界面后，图注要改成「界面示意」，否则是假证。

## 实拍叠加

**纯卡片讲"几秒切一次镜头"会被打回。** 观众要看的就是那几秒。讲节奏、机位、界面、成片效果的段一律嵌原片片段，卡片退到归纳位（见 `references/cutaway.md`）。

**`tpad` 加在 overlay 之后 = 定格到空白。** 视频 EOF 后 overlay 已经在输出底版帧，tpad clone 到的是"空洞底版"，实测一页 30 秒的后 4 秒洞里全黑。tpad 必须挂在视频端：`[1:v]crop=...,scale=...,fps=25,tpad=stop_mode=clone:stop_duration=3.8[v]`。

**整页视频页铺到 1920 会盖掉字幕。** 字幕已经烧在成片里（y≥1500），底版只做 1080×**1480**，overlay 写 `0:0`，字幕带自然保留。

**洞的比例必须等于 crop 比例。** 先定洞（988×559）再反推裁切（1024×580），反了就是压扁。误差 <1% 看不出，>5% 一眼变形。

**叠加是非破坏后置步骤，记得备份。** `compose.py` 出的成片先留一份 `final2.mp4`，`overlay.sh` 每次从它出发输出 `final.mp4`。改坏了随时回退，也不用重跑逐帧字幕合成。

**一次叠完所有片段，别一段一段叠。** 每叠一次重编码一次，画质掉一层，时长也可能被重采样带偏。叠加前后总时长必须一致（本片 379.913s 前后一致）。

## ego-browser 命令形式

**`ego-browser nodejs script.mjs` 会把文件路径当 JS 代码执行**，报 `ReferenceError: xxx is not defined`。必须走 stdin 重定向：`ego-browser nodejs < script.mjs`。

**`task.page(label)` 只能引用已存在的标签。** 传一个没见过的名字会报 `page label not found: u1`（后面还会列出当前可用的是 `p1`）。直接用 `task.page("p1")`，需要多页时用 `task.newPage()`。
